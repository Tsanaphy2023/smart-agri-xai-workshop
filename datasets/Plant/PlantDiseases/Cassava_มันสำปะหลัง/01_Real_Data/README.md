# 🌿 ชุดข้อมูลภาพจริง: โรคใบมันสำปะหลัง (Cassava Real Dataset)
- **แหล่งที่มา:** Kaggle Cassava Leaf Disease Classification (Makerere AI Lab)
- **จำนวนภาพ:** 21,367 ภาพ (CMD, CBB, CBSD, CGM, Healthy)
- **วิธีดาวน์โหลด:** สามารถดาวน์โหลดได้ผ่าน Kaggle API หรือหน้าเว็บ https://www.kaggle.com/c/cassava-leaf-disease-classification
- **หมายเหตุ:** ในโฟลเดอร์คู่ขนาน  มีภาพจำลองจัดเตรียมไว้ให้ทดสอบเรียบร้อยแล้ว
