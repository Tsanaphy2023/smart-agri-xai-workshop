# 🌾 ชุดข้อมูลภาพจริง: แมลงศัตรูข้าว (Rice Pest Real Dataset)
- **แหล่งที่มา:** IP102 Insect Benchmark Dataset (CVPR 2019)
- **แมลงที่เกี่ยวข้อง:** เพลี้ยกระโดดสีน้ำตาล (Brown Planthopper), หนอนกอข้าว (Rice Stem Borer), หนอนห่อใบข้าว (Leaf Folder)
- **วิธีดาวน์โหลด:** รันคำสั่ง 
ℹ️ คำแนะนำสำหรับ IP102 Insect Pest Benchmark Dataset (CVPR 2019):
   ชุดข้อมูลแมลงศัตรูพืชทางการเกษตรขนาดใหญ่ 75,000+ ภาพ 102 ชนิดแมลง (เพลี้ยกระโดด, หนอนกอ, หนอนกระทู้ ฯลฯ)
   🔗 ดาวน์โหลดได้ที่: https://github.com/xpwu95/IP102
   เนื่องจากชุดข้อมูลมีขนาดใหญ่ (หลายสิบ GB) แนะนำให้ดาวน์โหลดเฉพาะโฟลเดอร์พืชที่ต้องการใช้ในการอบรม
- **หมายเหตุ:** ในโฟลเดอร์คู่ขนาน  มีภาพจำลองจัดเตรียมไว้ให้ทดสอบเรียบร้อยแล้ว
