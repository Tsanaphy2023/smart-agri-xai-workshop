# 🏆 คลังโมเดลสำเร็จรูปพร้อมใช้งานสำหรับ Workshop (Ready-to-Use Agricultural Models)
## Embedded AI & Edge AIoT for Agriculture and Environment | มหาวิทยาลัยราชภัฏรำไพพรรณี

คลังโมเดลชุดนี้ถูกฝึกสอน (Transfer Learning) จากชุดข้อมูลภาพถ่ายแปลงเกษตรจริง 100% ด้วยสถาปัตยกรรม **MobileNetV3-Small** พร้อมส่งออกเป็นทั้ง **ONNX** (สำหรับ Web Dashboard / Streamlit) และ **TFLite** (สำหรับ Mobile Edge AI / Flutter) เพื่อให้ผู้เข้าร่วมกิจกรรมสามารถนำไฟล์โมเดลไปใช้งานได้ทันทีแม้ไม่สามารถฝึกสอนเองในวันจัดกิจกรรม

### 💻 วิธีนำไปใช้งานกับ Streamlit Web Dashboard:
1. เลือกไฟล์โมเดล `.onnx` ที่ต้องการ เช่น `smart_soil_type_model.onnx` หรือ `smart_durian_disease_model.onnx`
2. คัดลอกไปวางที่โฟลเดอร์หลักของโปรเจกต์ `smart-soil-ai/` ในชื่อ `smart_agri_model.onnx` พร้อมไฟล์ `labels.json`
3. ระบบใน `edge_classifier.py` และ `app.py` จะโหลดโมเดลที่ผ่านการเรียนรู้มาทำนายผลทันที

### 📱 วิธีนำไปใช้งานกับ Flutter Mobile App:
1. ไฟล์โมเดล `.tflite` ทั้งหมดถูกคัดลอกลงใน `digital_agri_xai_mobile/assets/models/` เรียบร้อยแล้ว
2. มีไฟล์ `labels.txt` ที่ระบุชื่อคลาสบรรทัดต่อบรรทัด
3. สามารถเรียกใช้งานผ่านแพ็กเกจ `tflite_flutter` เพื่อวินิจฉัยภาพบนมือถือแบบออฟไลน์ 100% ไร้อินเทอร์เน็ต
